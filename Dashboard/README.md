# Sales Analytics — Executive Dashboard

A static sales-analytics dashboard built from four CSV exports (orders, products,
users, destinations). No backend, no build step, no server required — this
recreates the original reference design (cream background, orange/dark accents)
wired up to your real data.

## Files

- `index.html` — page markup, loads the other three files in order
- `style.css` — all styling
- `data.js` — pre-aggregated data (compiled from the 4 source CSVs), exposed as
  `window.DASHBOARD_DATA`
- `app.js` — filtering, charts, tables, CSV export logic (reads `window.DASHBOARD_DATA`)

## Run it

Just open `index.html` directly in a browser (double-click it, or open it from
VS Code) — it works immediately, no local server needed. The data loads via a
plain `<script>` tag (`data.js`), not `fetch`, so it isn't blocked by `file://`
restrictions the way a separate `data.json` would be.

If you use the VS Code "Live Server" extension, that works too — either way is fine.

## What's on the dashboard

- **Executive Dashboard**: Total Revenue, Total Orders, Avg Order Value, Total
  Discount KPIs; Sales & Orders trend chart (Revenue / Orders Count / Combined);
  Top Products by Revenue; Top Destinations; eSIM vs Physical SIM split; Top
  Customers; Desk (staff) performance
- **Products / Customers / Orders Ledger tabs**: full sortable, searchable,
  paginated tables over the entire catalog/directory/ledger
- **Filters**: search box + Date Period + Product + Customer, all recompute the
  KPIs and charts live
- **Export CSV**: exports the currently filtered order set

## Deploy

Upload these 4 files as-is to any static host — nothing else is needed:

- **Netlify / Vercel**: drag-and-drop this folder, or connect a repo containing
  these files. No build command, output directory is `.`
- **GitHub Pages**: push the files to a repo and enable Pages on the branch/root
- **Any static bucket** (S3 + CloudFront, Cloudflare Pages, Firebase Hosting, nginx, etc.):
  upload the files as-is

## Updating the data

`data.js` was generated by aggregating the original CSVs (revenue, orders, top
products/destinations/customers, plus full catalogs for the Products/Customers/
Orders tabs). To refresh it with new CSV exports, re-run the aggregation script
and replace the JSON literal assigned to `window.DASHBOARD_DATA` in `data.js` —
no changes to `index.html`/`app.js`/`style.css` are needed as long as the JSON
shape stays the same.

HOW TO VIEW IT LOCALLY
------------------------

HOW TO DEPLOY IT
------------------
Any static hosting service works, since this is a single self-contained
HTML file. A few easy free options:

1) Netlify (drag & drop)
   - Go to https://app.netlify.com/drop
   - Drag this whole folder onto the page
   - You get a live URL in seconds

2) GitHub Pages
   - Create a new GitHub repo (e.g. "portfolio")
   - Upload index.html to the repo (must be named exactly "index.html"
     so it's picked up as the homepage)
   - Go to Settings -> Pages -> set source to your main branch
   - Your site goes live at https://<your-username>.github.io/portfolio

3) Vercel
   - Go to https://vercel.com/new
   - Import this folder / repo and deploy — no build step needed
